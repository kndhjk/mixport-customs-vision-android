Downloaded on 2026-10-04. Pixabay's license summary permits free use and adaptation without attribution, while prohibiting redistribution of the source asset on a standalone basis. These files are distributed only as integrated application feedback resources. Attribution is retained here for provenance and future license review.

The `HOLD` state uses Android's generated `ToneGenerator.TONE_PROP_BEEP2` and does not include a third-party audio file.
